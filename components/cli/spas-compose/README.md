# spas-compose CLI

**Status**: Planned for Phase 3 continuation  
**Purpose**: Service composition and domain choreography tooling

## Planned Features

- `spas-compose init` - Initialize a composition configuration
- `spas-compose add` - Add services to composition
- `spas-compose validate` - Validate composition compatibility
- `spas-compose generate` - Generate infrastructure code

## Current Status

This component is a placeholder for future development. Service composition features are deferred to Phase 3 as per the SPAS roadmap.

For current CLI capabilities, see the [`spas-service` CLI](../spas-service/README.md).
