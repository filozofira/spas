# SPAS SDK Schemas

This directory contains the canonical JSON Schema definitions shared across all SPAS SDK implementations. These schemas define the contract for service metadata that SDKs produce and the Repository validates.

## Schemas

| Schema | Purpose |
|--------|---------|
| [design-time-metadata-v1.schema.json](design-time-metadata-v1.schema.json) | Defines the structure of `spas.json` files generated by SDKs at build/development time |

## Usage

- **SDK Authors**: Validate generated `spas.json` against these schemas
- **Repository**: Uses these schemas for upload validation
- **CLI Tools**: Reference for metadata archive structure

## Schema Versioning

Schemas follow the `{purpose}-v{major}` naming convention. Breaking changes require a new major version (e.g., `design-time-metadata-v2`).
