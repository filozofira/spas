# SPAS Sidecar

Runtime sidecar deployed alongside each service in a SPAS domain.

It:

- Publishes events to Redis Streams (via `POST /publish`)
- Subscribes to events and invokes service HTTP endpoints (when `SERVICE_NAME` + `SERVICE_PORT` are set)
- Invokes commands via request/response (`POST /invoke/{command}`)
- Optionally emits Zipkin spans (when `ZIPKIN_URL` is set)

## Run locally

Prerequisites:

- Node.js 20+
- Redis

```bash
cd components/sidecar
npm install
npm run build
```

Start:

```bash
# Required
export CONFIG_PATH=./config.json
export REDIS_HOST=localhost
export REDIS_PORT=6379

# Optional
export SIDECAR_PORT=7000

# Enable subscriber/invocation (optional)
export SERVICE_NAME=order-service
export SERVICE_PORT=5001

# Tracing (optional)
export ZIPKIN_URL=http://localhost:9411
export TRACING_ENABLED=true

npm start
```

## Configuration

The sidecar loads configuration from a JSON file (typically generated by `spas-compose`).

- Schema: [schemas/sidecar-config-v1.schema.json](./schemas/sidecar-config-v1.schema.json)
- Example: [config.example.json](./config.example.json)

## Environment variables

| Variable | Required | Default | Notes |
| --- | --- | --- | --- |
| `CONFIG_PATH` | Yes | - | Sidecar config JSON path |
| `REDIS_HOST` | Yes | `localhost` | Redis hostname |
| `REDIS_PORT` | No | `6379` | Redis port |
| `SIDECAR_PORT` | No | `3500` | HTTP port for this sidecar (tooling often sets this to `7000`) |
| `SERVICE_NAME` | No | - | Target service host for subscriptions/invocations |
| `SERVICE_PORT` | No | - | Target service port |
| `ZIPKIN_URL` | No | - | Enables tracing when set |
| `TRACING_ENABLED` | No | `true` | Set `false` to disable tracing even if `ZIPKIN_URL` is set |
| `LOG_LEVEL` | No | `info` | `debug` enables verbose payload logs |
| `LOG_FORMAT` | No | `text` | `json` for structured logs |

## HTTP endpoints

- `POST /publish` (JSON body; routing uses the `x-event-type` header)
- `POST /invoke/{command}` (JSON body)
- `GET /health`
- `GET /ready`

## Transforms

Transforms use JSONata:

- Inline expressions are used as-is
- Paths ending in `.jsonata` are treated as files and loaded relative to the process working directory
