# Data Model: Agent Prompt Structure

**Date**: 2025-12-17 | **Plan**: [plan.md](plan.md) | **Spec**: [spec.md](spec.md)

## Overview

This document defines the structure of the enriched agent prompt generated by `spas-compose init`. The agent prompt is a Markdown file that serves as comprehensive instructions for AI agents performing choreography composition.

---

## Entity: Agent Prompt File

**Output Path**: `.github/agents/spas.compose.agent.md`  
**Max Size**: 25KB (SC-005)  
**Format**: GitHub-flavored Markdown

---

## Implementation Notes

1. **Template Literal Organization**: The `generateAgentFile()` function should be organized into sub-functions for each major section to improve maintainability.

2. **Dynamic Content**: The following should remain dynamic (populated from workspace):
   - Domain root path
   - Available services (from existing choreographies)
   - Existing sidecar config values

3. **Static Content**: The following should be embedded as static strings:
   - Technical Reference (CloudEvents, JSONata, etc.)
   - Known Pitfalls
   - Troubleshooting guides
   - Example templates

4. **Testing Strategy**: Each section should be testable independently via exported helper functions.
