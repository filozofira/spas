# Sidecar Contract

Specifies responsibilities and interfaces for the platform-injected sidecar/mesh.

## Responsibilities

- Traffic interception: ingress/egress
- Protocol translation: HTTP ↔ CloudEvents (PoC); gRPC ↔ events (Production)
- Transformation execution (inbound domain→internal, outbound internal→domain) via custom HTTP middleware (PoC) or sidecar native (Production)
- Identity propagation (PoC: payload-based; Production: middleware injection)
- mTLS termination (Production; PoC deferred)
- Schema validation (PoC optional; Production required)
- Observability: traces (Zipkin PoC), logs, metrics
- Policy enforcement: enclosure levels, egress allow-lists
- (Future) Idempotency enforcement & replay suppression based on `idempotency.strategy`

## Configuration

- Declarative config file(s) or environment variables
- Loads mapping specs referenced in `choreography.yaml` and `spas.json.mappings[]`
- Load priority: mounted files → config service → repository API
- Hot-reload supported (atomic swap; failure rollback)

## Health

- Sidecar exposes health/readiness
- Service exposes health or delegates to sidecar

## Compatibility

- PoC: SPAS sidecar component (custom implementation)
- Production: Compatible with standard service meshes (Istio, Linkerd) via sidecar contract

## PoC Implementation (SPAS Sidecar)

- Custom SPAS sidecar component (Node.js based)
- Handles pub/sub via Redis with transformation layer
- Wraps messages in CloudEvents 1.0 format with W3C Trace Context
- Configuration via JSON files (transformation rules, topic mappings, endpoints)
- Zipkin integration for distributed tracing
- Each service instance paired with dedicated sidecar instance
- HTTP endpoint for publish operations
- Redis subscription for consume operations
- Load configuration from mounted files (generated by CLI)
- Hot-reload supported via atomic config swap

## Production Implementation

- SPAS sidecar as reference implementation
- Compatible with service meshes (Istio, Linkerd) for complementary features (mTLS, policy)
- gRPC protocol support
- mTLS enforcement
- Schema validation integration
