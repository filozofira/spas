# Implementation Plan: spas-compose CLI

**Branch**: `005-spas-compose-cli` | **Date**: 2025-12-14 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/005-spas-compose-cli/spec.md`

## Summary

Build the spas-compose CLI tool for domain choreography composition with AI-in-the-loop assistance. The CLI provides three core commands (`init`, `services pull`, `choreography build`) while delegating complex semantic choreography composition to an AI agent via `/spas.compose` prompt. Uses JSONata for transformations (ADR-036) to maintain sidecar language flexibility.

## Technical Context

**Language/Version**: Node.js 20 LTS + TypeScript 5.3+  
**Primary Dependencies**: Commander.js 11.x (CLI), js-yaml 4.x (YAML parsing), jsonata 2.x (transformation validation), axios 1.x (HTTP client), chalk 4.x (terminal output)  
**Storage**: Local filesystem (domain workspace); SPAS Repository via HTTP  
**Testing**: Jest 29.x with ts-jest (unit + integration tests)  
**Target Platform**: Cross-platform CLI (Windows, macOS, Linux)  
**Project Type**: Single CLI project (mirrors spas-service structure)  
**Performance Goals**: Init <5s, Pull <10s per service, Deploy generation <30s  
**Constraints**: Must work offline after services pulled; deterministic generation  
**Scale/Scope**: PoC: 3-10 services per domain; 1-5 named flows per choreography
